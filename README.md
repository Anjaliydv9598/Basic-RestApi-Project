# Basic-RestApi-Project

This is a basic REST API project made using Spring Boot and Java.

I created this project to practice:
- REST APIs
- Spring Boot annotations
- Request handling
- API testing using Postman

## Tech Used
- Java
- Spring Boot
- Maven
- Postman
